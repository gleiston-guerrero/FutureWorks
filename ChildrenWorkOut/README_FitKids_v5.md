# FitKids v5 — Documento completo

## Resumen

Documento maestro **FitKids_v5_completo.docx** (~7.5 MB, 77 páginas en PDF de prueba) compuesto por:

1. **Páginas preliminares preservadas intactas** del documento original v4
   (portada, declaración de autoría, certificaciones, agradecimiento, dedicatoria,
   resumen, abstract, todos los índices y código Dublín)
2. **Cuerpo reescrito completo** desde la Introducción hasta el Capítulo VI
   Bibliografía (con redacción humanizada, normativa UTEQ aplicada, citas
   Mendeley reales y estructura conforme al reglamento)
3. **Anexos preservados intactos** del documento original v4

Este archivo contiene **189 campos Mendeley Cite reales** (188 citas + 1
bibliografía) gestionables desde el plugin Mendeley Cite de Word.

## Tareas obligatorias en Word al abrir el documento

### 1. Actualizar todos los índices (campos)

Con el documento abierto en Word:

- **Ctrl + A** (seleccionar todo el documento)
- **F9** (actualizar todos los campos)

Cuando aparezca el diálogo, elegir **"Actualizar toda la tabla"** para:
- Tabla de contenidos
- Índice de tablas
- Índice de figuras
- Índice de anexos
- Índice de ecuaciones

Esto regenerará los índices conforme a la estructura del cuerpo nuevo.

### 2. Reinsertar tablas y figuras del documento maestro

El documento contiene **placeholders punteados** con texto en cursiva gris
del estilo:

> *[Conservar la Tabla 2 original del documento maestro con las 11 fases TDDM4IoTS y entregables.]*

Cada uno indica el lugar exacto donde debe insertarse la tabla o figura
correspondiente del documento original v4. La integración es directa:
copiar la tabla/figura desde el v4 y pegarla sustituyendo el placeholder.

Las tablas y figuras que contienen el placeholder se identifican fácilmente
porque tienen un cuadro punteado y un texto introductorio en cursiva.

### 3. Mendeley Cite

Las 188 citas y la bibliografía completa son campos Mendeley Cite reales.
Si abres el documento con la extensión Mendeley Cite instalada, podrás
gestionar las referencias directamente: añadir, eliminar, cambiar de
estilo, etc.

La bibliografía está formateada en **estilo IEEE** (números entre corchetes,
ordenada por orden de aparición).
