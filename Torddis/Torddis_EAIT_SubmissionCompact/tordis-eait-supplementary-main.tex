\abstract{
    This document contains supplementary information for the manuscript entitled ``Torddis: A Real-Time IoT and AI-Based System to Support At-Home Learning and Mitigate Parental Absenteeism''. It provides the detailed acceptance test cases, the review of AI methods surveyed for the distraction-monitoring modules, and the preventive-maintenance plan for the Torddis system prototype. The main manuscript is self-contained; this material is provided for readers interested in reproducing the study.
}
