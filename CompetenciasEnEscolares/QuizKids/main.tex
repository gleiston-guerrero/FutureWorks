\chapter*{RESUMEN}
\addcontentsline{toc}{chapter}{RESUMEN}

El presente proyecto tecnológico tuvo como objetivo desarrollar \textbf{Kiddy Quiz}, una aplicación web inclusiva orientada a la evaluación y refuerzo de competencias curriculares en matemáticas para estudiantes de educación básica elemental. La fundamentación y el levantamiento de requisitos se sustentaron en una investigación de campo que incluyó entrevistas a cinco profesionales de la educación y dos psicopedagogos, lo cual permitió identificar las barreras cognitivas y de ansiedad presentes en los procesos evaluativos tradicionales del nivel elemental. El desarrollo del software se gestionó bajo la metodología ágil de Programación Extrema (XP), adaptada al contexto de un desarrollo individual mediante ciclos de retroalimentación con expertos. La arquitectura del sistema se construyó utilizando Angular para el \textit{frontend}, NestJS para la lógica del \textit{backend} y PostgreSQL como motor de base de datos relacional. Como principal innovación, la plataforma integra interfaces basadas en pictogramas para facilitar la navegación autónoma infantil, así como la implementación del modelo de Inteligencia Artificial generativa Gemini para proveer retroalimentación motivacional tras cada evaluación. La validación del sistema se realizó mediante la Escala de Usabilidad del Sistema (SUS) y el Modelo de Aceptación Tecnológica (TAM), demostrando una usabilidad en categoría \textit{Excelente} (media de 87,7 en estudiantes y 81,0 en docentes) y una intención de uso casi unánime por parte de los estudiantes (media de 4,93 sobre 5). Adicionalmente, para garantizar la protección de los datos y el control adecuado de roles, se implementaron medidas de seguridad mediante autenticación con tokens JWT. Como resultado, se ha consolidado una herramienta tecnológica inclusiva que optimiza la gestión académica del docente, reduce la frustración del estudiante y constituye un aporte significativo a la modernización de la evaluación educativa infantil en el contexto ecuatoriano.

\vspace{0.4cm}
\noindent\textbf{Palabras clave:} aplicación web; educación básica; matemáticas; pictogramas; inteligencia artificial; usabilidad; Kiddy Quiz.

% ============================ ABSTRACT ============================
\chapter*{ABSTRACT}
\addcontentsline{toc}{chapter}{ABSTRACT}

\selectlanguage{english}
The present technological project aimed to develop \textbf{Kiddy Quiz}, an inclusive web application designed for the evaluation and reinforcement of curricular competencies in mathematics for elementary basic education students. The theoretical foundation and requirements gathering were based on a field research study that included interviews with five education professionals and two psychopedagogues. This process enabled the identification of the cognitive and anxiety-related barriers that pervade traditional assessment practices at the elementary level. Software development was managed under the agile Extreme Programming (XP) methodology, adapted to the context of individual development through feedback cycles with experts. The system architecture was built using Angular for the frontend, NestJS for backend logic, and PostgreSQL as the relational database engine. As a primary innovation, the platform integrates pictogram-based interfaces to facilitate autonomous navigation for children, as well as the implementation of the Gemini generative Artificial Intelligence model to provide motivational feedback after each assessment. System validation was carried out using the System Usability Scale (SUS) and the Technology Acceptance Model (TAM), demonstrating an \textit{Excellent} usability rating (mean of 87.7 in students and 81.0 in teachers) and an almost unanimous intention of use among students (mean of 4.93 out of 5). Furthermore, to guarantee data protection and proper role-based access control, security measures were implemented using JWT token authentication. As a result, an inclusive technological tool has been consolidated, optimizing teachers' academic management, reducing student frustration, and constituting a significant contribution to the modernization of elementary educational assessment in the Ecuadorian context.

\vspace{0.4cm}
\noindent\textbf{Keywords:} web application; elementary education; mathematics; pictograms; artificial intelligence; usability; Kiddy Quiz.
